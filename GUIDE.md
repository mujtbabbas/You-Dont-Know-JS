# Reader's Guide — You Don't Know JS Yet (2nd Edition)

## What this project is

This is **You Don't Know JS Yet**, Kyle Simpson's book series diving deep into
the core mechanisms of the JavaScript language — this repository holds the
**second edition**. The full text of the books lives here as Markdown and can
be read online, for free, directly in the repository. Start with
[`preface.md`](preface.md) for the motivations and perspective behind the
series.

## How the content is organised

Each book lives in **its own folder**, with the chapters as Markdown files
inside and a `README.md` acting as that book's table of contents:

- `get-started/` — **Get Started**: orientation, pillars of JS, survey of the
  language.
- `scope-closures/` — **Scope & Closures**: lexical scope, closures, modules.
- `objects-classes/` — **Objects & Classes** ("The Unbooks", draft stable).
- `types-grammar/` — **Types & Grammar** ("The Unbooks", rough draft).
- `es-next-beyond/` and `sync-async/` — folders for the two further titles
  the README lists as canceled.

Supporting root files: `CONTRIBUTING.md` and `PULL_REQUEST_TEMPLATE.md`
(note the README states the series is complete and **not open to further
contributions**), and `LICENSE.txt` (CC BY-NC-ND 4.0).

## How to use it

Read the books **in the order the README recommends**:

1. [Get Started](get-started/README.md)
2. [Scope & Closures](scope-closures/README.md)
3. "The Unbooks" — [Objects & Classes](objects-classes/README.md), then
   [Types & Grammar](types-grammar/README.md)

Open a book's folder README and follow the chapter links. Print/retail
editions are linked from the main README (Leanpub and Amazon) if you prefer
paper or ebook formats.

## About this standalone edition

This repository is a standalone edition of
[getify/You-Dont-Know-JS](https://github.com/getify/You-Dont-Know-JS), based
explicitly on the upstream `2nd-ed` branch, converted from a fork into its own
repository and enhanced in place. See [`ENHANCEMENTS.md`](ENHANCEMENTS.md) for
what this edition adds and [`CHANGELOG.md`](CHANGELOG.md) for its version
history (v1.0.0 upstream baseline, v1.1.0 enhancements). All original work
belongs to Kyle Simpson and the You Don't Know JS contributors.
